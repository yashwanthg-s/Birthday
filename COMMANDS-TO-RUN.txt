git push -u origin main

═══════════════════════════════════════════════════════════════
STEP 2: DEPLOY BACKEND TO RAILWAY
═══════════════════════════════════════════════════════════════

1. Go to: https://railway.app
2. Click "Start a New Project"
3. Click "Deploy from GitHub repo"
4. Select your repository
5. Click on the deployed service
6. Go to Settings → Root Directory → Set to: backend
7. Go to Settings → Networking → Click "Generate Domain"
8. COPY THE URL (e.g., https://birthday-backend.railway.app)

═══════════════════════════════════════════════════════════════
STEP 3: UPDATE FRONTEND WITH BACKEND URL
═══════════════════════════════════════════════════════════════

# Edit this file: frontend/.env.production
# Replace with your Railway URL:

VITE_API_URL=https://YOUR-BACKEND-URL.railway.app

# Then commit and push:
git add frontend/.env.production
git commit -m "Update backend URL"
git push

═══════════════════════════════════════════════════════════════
STEP 4: DEPLOY FRONTEND TO VERCEL
═══════════════════════════════════════════════════════════════

1. Go to: https://vercel.com
2. Click "Add New Project"
3. Click "Import" next to your GitHub repository
4. Configure:
   - Framework Preset: Vite
   - Root Directory: frontend
   - Build Command: npm run build
   - Output Directory: dist

5. Click "Environment Variables"
   - Add variable:
     Name: VITE_API_URL
     Value: https://YOUR-BACKEND-URL.railway.app
     (Use the Railway URL from Step 2)

6. Click "Deploy"

7. Wait for deployment to complete

8. Your site will be live at: https://your-project.vercel.app
