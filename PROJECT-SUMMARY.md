## ✅ Setup Checklist

### Before You Start
- [ ] Node.js installed (v16+)
- [ ] Code editor ready
- [ ] Photos collected
- [ ] Birthday song downloaded

### Setup Steps
- [ ] Read START-HERE.md
- [ ] Edit App.jsx (name, age, birthday)
- [ ] Add photos to backend/public/photos/
- [ ] Add music as birthday-song.mp3
- [ ] Run `npm install` in backend
- [ ] Run `npm install` in frontend
- [ ] Start backend server
- [ ] Start frontend server
- [ ] Open http://localhost:3000

### Testing
- [ ] Landing page loads

## 🚀 Quick Commands

### Installation
```bash
# Backend
cd backend
npm install

# Frontend
cd frontend
npm install
```

### Running
```bash
# Terminal 1 - Backend
cd backend
npm start

# Terminal 2 - Frontend
cd frontend
npm run dev
```

### Building
```bash
cd frontend
npm run build
```
